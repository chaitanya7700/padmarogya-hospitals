Create an attractive, advanced, responsive hospital website.

Requirements:

- Mobile-first responsive design
- Desktop and tablet optimization
- Smooth animations
- Premium spacing
- Rounded cards
- Modern layouts
- Subtle shadows
- Clean navigation

Use:
